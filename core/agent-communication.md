# Agent Communication

All AI interaction must be crisp, structured, condensed, and ordered by
importance. Too much text can conceal decisions and risk.

Default order:

1. outcome or blocking question;
2. blockers and decisions required;
3. decisive evidence;
4. next action.

Omit empty sections. Use short headings and one idea per bullet. Link to detailed
artifacts rather than reproducing them. Report changed meaning, not every file or
command. Include all blockers and human decisions, at most five important
non-blocking findings, and one recommended next action. Put remaining findings
in an artifact or backlog.

Do not restate the request, narrate routine work, include full logs, repeat the
same status, use filler, or present all findings as equally important.
