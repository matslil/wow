# Shared Knowledge

Keep project-wide facts, source indexes, requirements, decisions, and unresolved
assumptions here. Put narrower knowledge in `<scope>/knowledge/` and link it from
that scope. Use [knowledge records](../templates/knowledge-record.md); concise
records may share a file when they support the same decision.

This template has no adopting project's facts. Replace this index with links to
actual project knowledge. WoW-specific rationale and validation are deliberately
in [maintenance/knowledge/](../maintenance/README.md), not inherited project facts.
Domain reference knowledge is in [engineering](../engineering/knowledge/README.md)
and [story](../story/knowledge/README.md).
