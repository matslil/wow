# Way of Working

A repository template for human-directed, agentic AI projects: efficient agent
work, high-quality results, and concise, discoverable communication. It supports
software engineering, stories, and projects combining several kinds of work.

Humans set goals and accept workflow changes. Agents research, implement, verify,
and deliver authorized work through pull requests, keeping humans informed of
changes to the knowledge behind the result.

## Start here

- Agents: read [AGENTS.md](AGENTS.md), then only applicable context.
- New projects: follow [template setup](templates/README.md).
- Existing projects: follow [adoption](workflows/adopt-existing-project.md).
- WoW maintainers: use [maintenance/](maintenance/README.md).
