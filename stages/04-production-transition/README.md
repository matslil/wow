# Production and Transition

Create reproducible release artifacts, acceptance evidence, configuration,
deployment or distribution procedures, migration and rollback plans, user and
operator information, and support readiness. Introduce the release without
losing required data, capability, or control.

The tollgate assesses reproducibility, acceptance, deployment, migration,
rollback, security, support, observation, and residual risk. A human authorizes
release and entry to Utilization.
Use [`tollgate.md`](tollgate.md).
