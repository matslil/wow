# Explore the System

Read `core/README.md`, the project definition, `starter/exploration/README.md`,
and this stage's `README.md`. Load no later-stage skill unless needed for a
specific dependency.

1. Define the problem or opportunity without assuming a solution.
2. Identify the system context, affected stakeholders, desired outcomes, and
   measures of effectiveness.
3. Record explicit facts, evidence, inference, unknowns, conflicts, and risks.
4. Select project-appropriate research, observation, experiment, or prototype
   methods from the tailored starter.
5. Update the authoritative model and trace evidence to findings.
6. Deliver each coherent change through a PR with verified commits.
7. Assess the Exploration tollgate and recommend an outcome.

Continue independent work while questions remain. Pause only when a human answer
is required and no useful authorized work remains. Never select or authorize the
next stage. Report the recommendation, blockers, decisive evidence, human
question, and next work concisely.
