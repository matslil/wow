# Exploration

Determine whether a problem or opportunity merits further investment. Define
the situation, system context, stakeholders, desired outcomes, assumptions, and
uncertainties. Gather evidence and test high-impact uncertainty without
prematurely committing to a solution.

The tollgate assesses problem understanding, stakeholder coverage, context,
value evidence, feasibility evidence, uncertainty, and risk. Recommend entry to
Concept only when the problem is worth pursuing and enough is known to compare
responses. A human authorizes the transition. Use [`tollgate.md`](tollgate.md).
