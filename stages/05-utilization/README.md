# Utilization

Observe the system in its intended context. Compare actual outcomes, quality,
incidents, usage, and environmental change with the model and intended need.
Trace observations to corrective work, new Exploration, or Concept activity.

The tollgate assesses achieved outcomes, operational control, feedback quality,
unresolved harm, sustainability, and continued need. A human decides whether to
continue use, evolve, restrict, pause, or begin retirement.
Use [`tollgate.md`](tollgate.md).
