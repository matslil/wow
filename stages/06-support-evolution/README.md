# Support and Evolution

Correct, adapt, secure, optimize, and extend the system through the same traced,
verified PR workflow as Development. Maintain compatibility decisions, supported
versions, operational knowledge, model accuracy, and release evidence. Material
changes may return to Exploration or Concept.

The tollgate assesses continued value, supportability, security, compatibility,
technical and operational risk, cost, replacement options, and archive readiness.
A human decides whether to continue support or authorize Retirement.
Use [`tollgate.md`](tollgate.md).
