# Evolve a Supported System

Read the core, project definition, this stage's `README.md`, and selected profiles.

1. Trace the operational observation, defect, risk, or need to the affected model.
2. Assess compatibility, versions, consumers, operations, and lifecycle impact.
3. Return material uncertainty or concept choice to the appropriate earlier stage.
4. Update model, implementation, verification, support, and release evidence.
5. Use one coherent PR; use multiple valid tested commits for a larger outcome.
6. Complete the PR and continue with the next authorized unblocked outcome.
7. Assess whether continued support remains viable or Retirement should begin.

Do not pause for review or ordinary engineering problems. Pause only when a
human answer is required and no independent work remains. A human accepts risk
and authorizes stage changes.
