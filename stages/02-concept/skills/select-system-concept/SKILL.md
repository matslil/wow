# Select a System Concept

Read the core, project definition, tailored Concept starter, and this stage's
`README.md`.

1. Confirm the Exploration baseline and unresolved uncertainty.
2. Define viable concepts, including a non-software response when credible.
3. Model boundaries, usage, structure, behavior, lifecycle effects, and risk at
   decision-appropriate depth.
4. Compare concepts using explicit criteria and evidence.
5. Record the recommendation, rejected alternatives, assumptions, and rationale.
6. Deliver model and decision changes through coherent PRs with verified commits.
7. Assess Concept maturity and state the exact human decision required.

Do not treat the recommendation as selection or authorize Development. Continue
unblocked work; pause only for a required human answer. Keep output condensed.
