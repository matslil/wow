# Concept

Develop and compare viable responses. Model candidate boundaries, usage,
structure, behavior, constraints, lifecycle implications, and principal risks
at the depth needed for a defensible decision. Record alternatives and rationale.

The tollgate assesses outcome clarity, alternative coverage, analysis quality,
concept feasibility, initial architecture, lifecycle viability, risk, and
verification strategy. A human selects the concept and authorizes Development.
