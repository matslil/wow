# Retirement

Withdraw the system, version, capability, or component deliberately. Identify
consumers and dependencies; migrate or export data; revoke access and
infrastructure; communicate end of support; and verify withdrawal.

Archive source, history, model, decisions, requirements, tests, evidence,
releases, build instructions, dependencies, licenses, provenance, and restoration
instructions. Classify assets for reuse, repurposing, recycling, retention, or
disposal. A human accepts retirement completion and residual obligations.
Use [`tollgate.md`](tollgate.md).
