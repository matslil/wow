# Mandatory Project Definition

Every adopting project supplies [`project.yaml`](project.yaml). It defines the
system and authorities the methodology cannot safely assume. Blank, inferred,
or example values do not satisfy required fields.

The project also records starter dispositions in `tailoring.yaml`. Existing
projects may begin with a provisional manifest created by the adoption workflow;
each inferred value remains marked until a human confirms it.
