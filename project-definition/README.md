# Project Definition

Complete [project.yaml](project.yaml) with project-specific goals, scope, work types,
authorities, paths, and checks. Replace `required` values; inferred values stay
provisional until the human confirms them. Do not block unrelated work on unused
fields. Mark domain-specific fields not applicable when that domain is absent.

Record selected guidance and justified exceptions in [tailoring.yaml](tailoring.yaml).
Tailoring cannot silently override human intent or accepted shared rules; process
changes require human review. Existing projects may adopt incrementally using
[the adoption workflow](../workflows/adopt-existing-project.md).

These files are templates. WoW's own definition is in
[maintenance/knowledge/project.md](../maintenance/knowledge/project.md).
