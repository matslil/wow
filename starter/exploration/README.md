# Exploration Starter

Required outcomes are an understood problem or opportunity, identified context
and stakeholders, explicit uncertainty, evidence about value and feasibility,
and a recommendation. Select suitable methods such as interviews, observation,
repository or operational analysis, research, experiments, prototypes,
simulation, or workshops. A prototype is evidence, not automatically the
production architecture.

Projects may replace the method and artifact set, but must map replacement
evidence to these outcomes.
