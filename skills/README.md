# General Skills

Load only the skill needed for the current outcome. Scoped skills live with their
own domain or module; changes to any workflow require human review and acceptance.

| Trigger | Skill |
| --- | --- |
| New human request | [Handle request](handle-request/SKILL.md) |
| Missing or uncertain knowledge; external input | [Research knowledge](research-knowledge/SKILL.md) |
| Output ready for checking, or a failed check | [Verify output](verify-output/SKILL.md) |
| Repeated friction or substantial delivery | [Retrospective](run-methodology-retrospective/SKILL.md) |

Domain entry points: [engineering](../engineering/README.md),
[story](../story/README.md). WoW-only work uses
[maintain-wow](../maintenance/skills/maintain-wow/SKILL.md).
